vibe-sfu conference client

This demo inverts the usual roles: the SFU makes every offer. Joining is one round trip — the server's first offer already contains its own data channel, your uplink sections, and a downlink for everyone already in the room. When somebody joins or leaves, the server re-offers over that data channel; the browser only ever answers, so there is no glare. Open this page in several tabs to watch tiles appear and disappear.
